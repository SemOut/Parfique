# Parfique

The website for Parfique, an independent fragrance studio.

## Open the website

Open `index.html` directly in a browser. No npm, build tool, server, or dependencies are required.

## Project structure

- `assets/Logo.png` - Parfique logo asset used across the site
- `index.html` - page structure and content
- `about.html` - the Parfique story
- `product.html` - reusable product detail page
- `contact.html` - contact page
- `styles.css` - responsive visual system
- `main.js` - product selection and detail-page behavior
